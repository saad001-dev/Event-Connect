# Event Connect

A modern web application to connect people with events, networking opportunities, and communities.

## 🚀 Features

- User Authentication (Login/Register)
- Create and Manage Events
- Networking Page for Professionals
- User Profiles
- Session Management
- Responsive Design

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Vite
- React Router
- CSS3

**State Management:**
- Zustand

**Other Tools:**
- Axios
- ESLint
- Git & GitHub
